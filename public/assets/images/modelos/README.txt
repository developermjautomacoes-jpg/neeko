MODELOS (NEEKO MODELO)
======================
Salve aqui a imagem com a grade dos 8 cards "Neeko Modelo"
(a que foi enviada no chat), por exemplo com o nome:

    grade-modelos.png   (ou .jpg)

A partir dela eu corto os 8 cards individuais automaticamente,
otimizo para web e coloco no site (esteira / portfólio / hero).

Se preferir, você também pode salvar os 8 cards já separados
(1 arquivo por nicho) — funciona do mesmo jeito.
