LOGOS DOS CLIENTES
==================
Coloque aqui os arquivos das logos dos clientes (PNG com fundo transparente
ou branco, ou SVG). Depois referencie em src/config/content.js -> clients.logos:

  { src: "/assets/images/clients/arquivo.png", alt: "Nome do cliente" }

Os cards padronizam automaticamente o tamanho (altura fixa de 56px por logo),
então não é preciso redimensionar manualmente. Ideal: fundo transparente.

Arquivos esperados já referenciados no content.js:
  - crces-mulher.png   (CRC-ES Mulher)
  - facilitar.png      (Facilitar Serviços Contábeis)
